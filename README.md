# حلّ معي — vvv

منصة تعليمية عربية تفاعلية تعرض مسائل الدرس من ملف JSON وتساعد الطالب على حلها خطوة بخطوة.

## المزايا

- رفع ملف JSON وتحويله مباشرة إلى درس تفاعلي
- شرح الخريطة الذهنية والهدف قبل كل خطوة
- إجابات اختيار من متعدد
- حاسبة مدمجة
- مساعدة تحل الخطوة مقابل 4 تفاحات
- تلميح ومواضيع مرتبطة مقابل تفاحتين
- 100 تفاحة تتجدد يوميًا
- 10 قلوب لكل سؤال
- دعم الرسومات المرفقة داخل JSON
- تصميم عربي متجاوب مع الهاتف

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح، ثم اضغط **إضافة JSON** واختر ملف الدرس.

## بنية البيانات

يعتمد الموقع على الحقل `exam_questions`، وداخل كل سؤال مصفوفة `interactive_steps` وفق النموذج المستخدم في المشروع.
