# سيف وقلم — محرك المعلم الذكي

واجهة تعليمية عربية للطلبة العراقيين بشخصية **أستاذة نورة**. تبدأ بتعارف منطقي من أربع خطوات، تحفظ ملخصًا ديناميكيًا، ثم تفتح مسار التعلّم والمسائل المستوردة.

## ما تم بناؤه

- React + TypeScript، واجهة محادثة RTL ومتجاوبة مع الهاتف.
- آلة حالات: الاسم ← المحافظة ← الصف ← الحلم.
- تحقق محلي للعرض التجريبي، وCloudflare Worker للتحقق الذكي عبر Gemini.
- DB2 مستقلة بجداول `ai_student_profiles` و`chat_history` و`curriculum_paths`.
- لا يوجد في الكود أي اتصال أو مفتاح أو استعلام إلى DB1.
- تصحيح البيانات السابقة عبر `corrections`، وعدم رفع الخطوة عند فشل التحقق.
- ست مسائل ورسومات من `Exam_Processed_Pages_Bundle_2026-09-26.zip` داخل دفتر التعلّم.
- Manifest لتثبيت الواجهة كتطبيق PWA.

## التشغيل

```bash
npm install
npm run dev
```

من دون `VITE_API_BASE` تعمل الواجهة بوضع تجريبي محلي. للإنتاج:

1. أنشئ مشروع Supabase منفصلًا خاصًا بـDB2 وشغّل `migrations/001_ai_engine_db2.sql` داخله فقط.
2. أضف أسرار Worker عبر `wrangler secret put`.
3. اضبط `ALLOWED_ORIGIN` على نطاق الواجهة.
4. انشر Worker ثم ضع رابطه في `VITE_API_BASE` عند بناء الواجهة.

## قاعدة الأمان

DB1 مسؤول عن تسجيل الدخول فقط. الواجهة ترسل معرفًا معتمًا للطالب إلى Worker. Worker وحده يقرأ ويكتب DB2. مفتاح Service Role يبقى سرًا داخل Worker ولا يصل إلى المتصفح.
